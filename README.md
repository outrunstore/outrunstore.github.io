# OUTRUN Store

Website van OUTRUN: streetwear (trainingspakken, puffers, sneakers, petten en mutsen). Klanten kiezen een product, kleur en maat en bestellen via Snapchat (`outrun.store`).

## Aanpassen

Alles zit in `index.html`. Onderaan in het `<script>`-blok staan:

- `CONFIG`: Snapchat-naam, naam van de drop, `dropLive` (false = reserveren, true = drop is live) en KvK-nummer
- `PRODUCTS`: de producten met naam, categorie, prijs, kleuren en maten

## Online

De site draait op GitHub Pages: https://outrunstore.github.io
